Formulario de captura
  • Beneficiario: a quién se le reembolsa el dinero.
  • Fecha: viene puesta la de hoy. No se puede poner una fecha más allá de mañana.
  • Monto: con centavos. Tiene que ser mayor a $0.
  • Concepto: lo eliges de la lista (papelería, gasolina, etc.). Comidas no aparece aquí a propósito.
  • Quién autoriza: empieza a escribir y sale la lista; también puedes escribir un nombre.
  • Comprobantes: adjunta al menos uno (foto, PDF o Excel). Puedes subir varios.
  • Registrar Reembolso: guarda todo. Aparece ✅ Reembolso registrado y el formulario se limpia.
El sistema lo pone soloNo tienes que escribir quién entrega, tu usuario ni la sucursal: todo eso se guarda automáticamente con tus datos. El reembolso nace en estado Pendiente.
Reglas de los comprobantes
  • Obligatorio adjuntar al menos uno.
  • Solo se aceptan fotos JPG/PNG, PDF o Excel (.xls/.xlsx).
  • Máximo 10 MB por archivo.
Las comidas NO se capturan aquíSi intentas registrar una comida, sale el aviso: "Las comidas se registran desde el módulo de Comidas, no aquí." Las comidas las autoriza el gerente; tú solo las pagas en la pantalla Pago de Comidas.

Arriba: pendientes por enviar. Abajo: lotes ya enviados.
  • Enviar a corte: el paso principal. Manda todos los pendientes juntos.
  • Verificar respuestas: refresca para ver si el autorizador ya aprobó o rechazó.

Cómo enviar a corte, paso a paso

  1. Revisa la lista de pendientes (los indicadores de arriba te dicen cuántos son y el total).
  2. Toca Enviar a corte.
  3. Aparece una ventanita que pide el número de lote. Escribe solo números (por ejemplo 41).
  4. Listo: el sistema arma el lote como 41-JOSE (tu nombre) y todos los pendientes pasan a En corte.
  5. Sale el mensaje ✅ Lote enviado a corte. El autorizador ya lo verá en su módulo.
Ojo
  • El número de lote debe ser solo números. Si escribes letras, no lo acepta.
  • Si no hay pendientes, el botón Enviar a corte no funciona.
  • Se envían todos los pendientes de una vez, no de uno en uno.

Ventana "Cobro de comidas"
  1. El empleado llega con su código de 6 dígitos (lo recibió por WhatsApp o lo ve en su app).
  2. En su fila, toca Cobrar con código. Se abre la ventana Cobro de comidas.
  3. Escribe el código de 6 dígitos que te dicta el empleado.
  4. Toca Confirmar pago (se activa solo cuando hay 6 dígitos).
  5. Si es correcto, sale ✓ Pago liberado con el monto exacto a entregar. Entrega ese efectivo y luego toca Listo.
El código del día
  • Es un código por empleado y por día. El de ayer ya no sirve; cada día se genera uno nuevo y vence a las 11:59 pm.
  • Un solo código cubre TODAS las comidas pendientes de ese empleado de una vez (por eso ves varias comidas con un total sumado; le pagas todas juntas).
Solo de lunes a sábadoEl domingo aparece "Pagos deshabilitados — Los pagos de comidas solo se pueden realizar de lunes a sábado" y el botón de pago se apaga.

Si algo sale mal

Mensajes que puedes ver y qué significan.

Al capturar un reembolso

MensajeQué hacer
"Completa todos los campos obligatorios"Falta llenar un campo con *.
"El monto debe ser mayor a 0"Escribe un monto válido.
"La fecha no puede ser mayor a mañana"Corrige la fecha.
"Debes adjuntar al menos un comprobante"Adjunta una foto, PDF o Excel.
"Archivo muy grande (máx 10MB)"Usa un archivo más ligero.

Al pagar una comida

MensajeQué significa / qué hacer
"No hay código generado para este empleado…"Todavía no se le ha generado código. Que abra su app.
"El código ya venció"Era de otro día. Necesita el código de hoy.
"Este código ya se usó"El pago ya se había liberado antes.
"Código incorrecto"Revisa los 6 dígitos e intenta de nuevo.
"Demasiados intentos fallidos"El empleado debe abrir su app para obtener un código nuevo.
"Ya no tiene comidas pendientes"No se pagó nada; el código sigue disponible.
Regla de oroSi un mensaje no te deja avanzar, no insistas a la fuerza: lee lo que dice, corrige ese punto, y si sigue igual avisa a administración.
